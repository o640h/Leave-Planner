## Governance note

The PDFs state that their intranet versions are the maintained copies and printed/downloaded copies are uncontrolled. The encoded application rules therefore require confirmation by the relevant Trust policy owner before production use. Both documents list July 2030 as their next review date.

The workbook is evidence of the existing workflow, not an authoritative rules engine. Known anomalies include overlapping count formulas, two dates outside the stated leave year, a broken named range, and hard-coded activity additions that are not fully explained by the sheet.
